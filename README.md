# sstq

## Назначение
**SSTQ** - инструмент для оценки системы распознавания речи. Он помогает измерить, насколько точно система распознала аудио, сравнивая результаты с эталонными гипотезами распознавания

## Иcпользованные инструменты
Инструмент разработан на Go 1.26.4

#### Внешние утилиты

**FFmpeg** - используется для конвертации аудио в нужные форматы
**ffprobe** - используется для проверки аудиофайлов в валидации
**whisper-cli** - используется для распознавания речи и составления гипотез

## Cтруктурa Golos
**Golos** - речевой корпус на русском языке от Сбера. Содержит записи русской речи с расшифровками.

#### Структура корпуса

```
test.tar (≈1.3 ГБ)
├── crowd/
│   ├── manifest.jsonl          # манифест crowd
│   ├── manifest.tsv            # манифест в TSV формате
│   └── files/                  # аудиофайлы
│       ├── 00b1dd4be8a32fc7e4ab7aaffb9666e0.wav
│       ├── 0a1f4e8c2b3d5f7e9a1b2c3d4e5f6a7b.wav
│       └── ...
└── farfield/
    ├── manifest.jsonl          # манифест farfield 
    ├── manifest.tsv            # манифест в TSV формате
    └── files/                  # аудиофайлы
        ├── 8a5e04c1597e8f0d1c2b3a4f5e6d7c8b.wav
        └── ...

```
В корпусе находятся две категории записей:
* **crowd** - обычные записи русской речи
* **farfield** - записи на расстоянии от микрофона

## Формат исходного и итогового manifest

#### Исходный манифест (Golos)

**Формат исходного манифеста:** jsonl. Он содержит информацию о всех записях для каждой категории.

###### Формат записи

Каждая строка в манифесте — это JSON-объект с тремя полями:
```
{
  "audio_filepath": "files/e632f7d39c15e7edfc665b91e6f2071f.wav",
  "text": "афина воспроизведи музыку вперемешку",
  "duration": 4.9
}
```
###### Поля исходного манифеста

|Поле|Тип|Описание|
|-|-|-|
|audio_filepath|string|Путь к аудиофайлу|
|text|string|Расшифровка|
|duration|float64|Длительность аудио в секундах|

#### Итоговый манифест (STTQ)

**Формат итогового манифеста:** jsonl. Он создается после импорта корпуса и содержит всю необходимую информацию для дальнейшей работы

###### Формат записи

Каждая строка в манифесте — это JSON-объект с набором полей:
```
{
  "id": "crowd-134300811b0f",
  "audio": "audio\\crowd-134300811b0f.wav",
  "text": "показывай видео михаил ломоносов",
  "language": "ru",
  "duration_ms": 4180,
  "sample_rate": 16000,
  "channels": 1,
  "tags": ["crowd"],
  "sha256": "b4e402350bf01dae4cc4f74161ad25e77c5070ef779a9c62534a3714b2bf2383"
}
```
###### Поля итогового манифеста

|Поле|Тип|Описание|
|-|-|-|
|id|string|Уникальный идентификатор записи|
|audio|string|Относительный путь к аудиофайлу|
|text|string|Эталонная расшифровка|
|language|string|Язык записи|
|duration_ms|int64|Длительность в миллисекундах|
|sample_rate|int|Частота дискретизации (Гц)|
|channels|int|Количество каналов (1 = моно)|
|tags|[]string|Теги записи|
|sha256|string|SHA-256 хеш аудиофайла|

## Выборка и квоты

Из полного корпуса Golos выбирается некоторое количество записей для тестирования. Выборка должна:
* Включать записи обеих категорий
* Быть детерминированный 
* Учитывать квоты для категорий
* Фильтровать по длительности
* Ограничивать общее количество 

#### Команда
```
sttq corpus import-golos --archive test.tar --quota crowd=200 --quota farfield=50 --seed internship-2026 --limit 250 --max-duration 30m --out corpus
```
##### Параметры выборки
|Параметр|Описание|По умолчанию|
|--quota crowd|Количество записей из категории crowd|200|
|--quota farfield|Количество записей из категории farfield|50|
|--limit|Количество записей|250|
|--max-duration|Максимальная длительность записи| 30m|
|--seed|Seed для выборки|intrship-2026|

**Квоты** определяют, сколько записей берется из каждой категории
**Сид** определяет детерминированность - одинаковый сид выдает одинаковый итоговый манифест

## Подготовка аудио

Подготовка аудио приводит все аудиофайлы к единому формату, что необходимо для распознавания речи (whisper.cpp). Подготовка подгоняет все файлы к одинаковым параметрам: частоте, дисктеризации, количеству каналов.

#### Команда
```
sttq audio prepare --manifest ./corpus/manifest.jsonl --profile wav-16k --workers 4 --timeout 30s --out ./corpus
```
##### Параметры подготовки
|Параметр|Описание|По умолчанию|
|-|-|-|
|--manifest|Путь к манифесту|./corpus/manifest.jsonl|
--profile|Профиль конвертации|wav-16k|
--workers|Количество параллельных процессов|4|
--timeout|Таймаут на одну запись|30s|
--out|Выходная папка|./corpus|

Для работы необходим FFmpeg

**Формат итоговых гипотез:** jsonl. Он содержит результаты распознавания речи (гипотезы) для каждой записи корпуса.
###### Формат записи


## WER, CER и нормализация

Перед сравнением тексты приводятся к единому виду. Номализация одинаково применяется к эталону и к гипотезе. Реализовано два профиля нормализации

###### Профили нормализации
|Профиль|Применяемые преобразования|
|-|-|-|
|strict|NFC, схлопывание пробелов, удаление пробелов по краям|
|ru-default|NFC, нижний регистр, замена ё на е, замена пунктуации на пробелы, схлопывание пробелов, удаление пробелов по краям|

###### strict 
Сохраняет регистр и пунктуацию. Минимальное изменение исходного текста

Пример:
```
Вход:   "Привет,   мир!  "
Выход:  "Привет, мир!"
```
###### ru-default
Полная нормализация для русского языка

Пример:
```
Вход:   "Ёжик, где ты?"
Выход:  "ежик где ты"
```
##### WER (Word Error Rate)

Отражает долю ошибок на уровне слов
```
WER = (S + D + I) / N
```
Где: 
S - Substitutions — замены
D - Deletions — удаления
I - Insertions — вставки
N - Количество слов в эталоне

**Алгоритм**
1. Разбивка на слова
2. Алгоритм Левенштейна с обратным проходом
3. Подсчет операций
4. Расчет метрики
###### Пример сравнения
```
Эталон:   мама мыла раму    (3 слова)
Гипотеза: мама мыла ламу    (3 слова)

Сравнение:
- мама == мама - совпадение
- мыла == мыла - совпадение
- раму -> ламу - замена

S = 1, D = 0, I = 0, N = 3
WER = (1 + 0 + 0) / 3 = 0.333
```
Общий WER считается по суммарным счетчикам

##### CER (Character Error Rate)

Отражает долю ошибок на уровне символов (рун)
```
СER = (S + D + I) / N
```
Где: 
S - Substitutions — замены
D - Deletions — удаления
I - Insertions — вставки
N - Количество символов в эталоне

**Алгоритм**
1. Разбивка на слова
2. Алгоритм Левенштейна с обратным проходом
3. Подсчет операций
4. Расчет метрики
###### Пример сравнения

```
Эталон:   мама мыла раму    (14 символов)
Гипотеза: мама мыла ламу    (14 символов)

Сравнение по символам:
м=м , а=а , м=м , а=а ,
пробел=пробел ,
м=м , ы=ы , л=л , а=а ,
пробел=пробел ,
р=л ошибка! , а=а , м=м , у=у

S = 1, D = 0, I = 0, N = 14
CER = 1 / 14 = 0.071
```
Общий СER считается по суммарным счетчикам

## Команды CLI

#### 1. Оценка качества
**evaluate**

Оценка качества распознавания по эталону и гипотезам.

```
sttq evaluate --manifest <путь> --hypotheses <путь> --normalization ru-default--out report.json
```

###### Флаги
|Флаг|Описание|
|-|-|
|--manifest|Путь к манифесту|
|--hypotheses|Путь к гипотезам|
|--normalization|Профиль нормализации|
|--out|Путь сохранения отчета|

#### 2. Импорт корпуса
**corpus import-golos**
Импорт корпуса Golos из архива test.tar.

```
sttq corpus import-golos --archive <путь> --quota crowd=200 --quota farfield=50 --seed internship-2026 --limit 250 --max-duration 30m --out ./corpus
```

###### Флаги
|Флаг|Описание|
|-|-|
|--arhive|Путь к архиву|
|--quota crowd|Квота для crowd|
|--quota farfield|Квота для farfield|
|--seed|Сид для выборки|
|--limit|КОличество записей|
|--max-duration|Максимальная длительность|
|--out|Выходная папка|

#### 3. Подготовка аудио
**audio prepare**
Конвертация аудио в единый формат
```
sttq audio prepare --manifest <путь> --profile wav-16k --workers 4 --timeout 30s --out ./corpus
```

###### Флаги
|Флаг|Описание|
|-|-|
|--manifest|Путь к манифесту|
|--profile|Профиль конвертации|
|--workers|Количество параллельных процессов|

#### 4. Распознавание
**run whispercpp**
Запуск распознавания через whisper.cpp.
```
sttq run whispercpp --manifest <путь> --binary <путь> --model <путь> --language ru --workers 2 --timeout 2m --out ./runs/whisper.jsonl
```

###### Флаги
|Флаг|Описание|

|--model|Путь к модели|

|--timeout|Таймаут на запись|

#### 5. Отчеты
**report**
Конвертация JSON-отчета в HTML.

```
sttq compare --baseline <путь> --current <путь> --max-wer-delta 0.02 --max-cer-delta 0.02
```

#### Полный сценарий
```
# 1. Импорт корпуса
sttq corpus import-golos --archive test.tar --out ./corpus

# 2. Подготовка аудио
sttq audio prepare --manifest corpus/manifest.jsonl --out ./corpus

# 3. Распознавание
sttq run whispercpp --manifest corpus/manifest.jsonl --out runs/whisper.jsonl

# 4. Оценка качества
sttq evaluate --manifest corpus/manifest.jsonl --hypotheses runs/whisper.jsonl --out report.json

# 5. Отчет
sttq report --input report.json --out report.html

# 6. Сравнение
sttq compare --baseline baseline.json --current current.json
```
